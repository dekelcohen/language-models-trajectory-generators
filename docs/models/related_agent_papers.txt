* Title: CaP-X - CaP-X: A Framework for Benchmarking and Improving Coding Agents for Robot Manipulation
  ) Goal: natural language task + RGB-D/state observations --> LLM/VLM coding agent writes Python programs composing perception (SAM3, Molmo 2, OpenCV, Open3D) and control (PyRoki IK/motion-planning) primitives in CaP-Gym (Gymnasium REPL) --> CaP-Bench scores 12 frontier models across abstraction/interaction/grounding tiers --> insights used to build CaP-Agent0 (training-free agentic harness) and CaP-RL (GRPO-trained coding policy) --> executed program controls robot in sim or real
  ) Problem: unclear how much Code-as-Policy performance comes from the agent vs from human-tuned high-level primitives (designer scaffolding)
    ) Also unclear whether more test-time compute can compensate for low-level interfaces
  ) Tags: VLM, Planning, PrimitivePolicies, Zeroshot, Closed-Loop, TextPrompt, ImagePrompt, Segmentation, MotionPlanner, RL, AutoReward, Sim2Real, Long Horizon

  ) Method: CaP-Gym binds the env loop (sim or real) to a stateful Code Executor loop
    ) One turn: agent receives obs, writes a Python program, env executes it fully (may call several primitives), returns stdout/stderr/images
    ) Never resets mid-trial
    ) Data Collection: no human demos
      ) Human-expert-written Python reference solutions used as upper bound

    ) Inference: 8 tiers (S1-S4 single-turn, M1-M4 multi-turn) vary primitive abstraction, in-context examples and visual grounding (raw images vs VDM text)

      ) Close-loop: multi-turn tiers feed back stdout/stderr (M1), raw RGB (M2) or VDM text diffs (M3/M4) each turn; agent retries/debugs without env reset

  ) Pro: code-as-action-space transfers sim to real because primitives are shared
    ) Note: very relevant to our repo - text scene diffs beat raw images as multi-turn feedback
