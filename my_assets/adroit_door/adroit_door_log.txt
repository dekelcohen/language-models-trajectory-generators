  URDF Details

  - Hinge joint door_hinge with axis z, limits 0 → 1.57 rad (0–90°), damping=1, friction=2.
  - Latch joint latch_joint with axis y, limits 0 → 1.8 rad, damping=0.5, friction=5.
  - Inertias and masses copied from MJCF for frame, door, and latch.
  - Visuals use primitive shapes (box/cylinders) with wood/metal colors; no external meshes required.

  Integration Notes

  - Load happens in Environment.load() with:
      - p.loadURDF("my_assets/adroit_door/adroit_door.urdf", [-0.11, 0.04, 0.45], q=[0,0,0,1], useFixedBase=True)
      - Joint names are matched to URDF: door_hinge and latch_joint.
  - Motors initialized to hold at zero position (closed door and latch).

  How To Drive The Door

  - Single-joint control:
      - env.set_door_state(door_angle=1.0)  opens the door to ~57°.
      - env.set_door_state(latch_angle=1.0) rotates the latch.
  - Batch control:
      - env.set_door_state_array(door_angle=1.0, latch_angle=0.5)  controls both at once.

  Example Usage

  - In run_simulation_environment, after env.load():
      - env.set_door_state(door_angle=0.8, latch_angle=0.4)
      - Step a bit to settle: for _ in range(100): env.update()

  Design Choices

  - Geometry: faithfully mapped MJCF sizes (MuJoCo half-sizes converted to full box size; cylinder lengths preserved). Using primitives
    keeps it simple and consistent with existing YCB URDF style when meshes aren’t available.
  - Dynamics: MJCF damping/friction mapped to URDF <dynamics> tags; efforts/velocities set to reasonable values for PyBullet motors.
  - Position: Door frame placed near MJCF frame body pose; hinge origin 0.31 0 0 matches MJCF.
